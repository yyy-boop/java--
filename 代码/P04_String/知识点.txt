第4集 String 类型

一、字符串基础

1. String 是引用数据类型，类名大写开头，拥有自己的方法；基本类型名都是小写开头。

2. length()：返回字符串长度。

3. toLowerCase()：全部转成小写；toUpperCase()：全部转成大写。

4. trim()：去掉字符串首尾的空格。

5. indexOf(字符或子串)：返回第一次出现的索引，索引从 0 开始；找不到返回 -1。

二、拼接与转义

1. 字符串拼接直接用 +，字符串与数字拼接时，数字会自动转成字符串。

2. + 从左向右结合：
   1 + 2 + "c" 先做加法得 3，再拼接，结果是 3c；
   "c" + 1 + 2 一直是字符串拼接，结果是 c12，而不是 c3。

3. 字符串中要出现双引号，需要用反斜杠转义，写成 \"。

4. 常用转义字符：\n 换行、\t 制表符、\b 退格、\r 回车、\\ 表示一个反斜杠。

三、比较与修改

1. String 是引用类型，用 == 比较的是内存地址，两个内容相同的字符串地址可能不同。

2. 比较字符串内容是否相同要用 equals()，它区分大小写。

3. 不区分大小写的比较用 equalsIgnoreCase()。

4. 修改类方法：
   toLowerCase / toUpperCase 转换大小写；
   trim 去首尾空格；
   replace('旧字符','新字符') 替换单个字符；
   replace("旧子串","新子串") 替换一段子串。

5. String 本身不可变，这些方法都不是修改原字符串，而是返回一个新字符串。

四、分割、拼接、判断与子串

1. split(分隔符)：按分隔符把一个字符串切分成字符串数组，例如按逗号切分。

2. String.join(连接符, 元素...)：把多个字符串元素用连接符拼成一个大字符串。

3. startsWith(前缀)：判断字符串是否以指定前缀开头。

4. endsWith(后缀)：判断字符串是否以指定后缀结尾。

5. isEmpty()：判断是否为空字符串（长度为 0）。Java 8 中没有 isBlank。

6. substring(起始索引, 结束索引)：截取子串，规则是左闭右开，即包含起始位置、不包含结束位置。

对应代码见 StringBasic.java 与 StringMore.java。
