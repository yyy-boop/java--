# Java 复习代码

整理自 B 站视频《Java 基础知识点速通》（BV1Nmd5YYEWK），共 **34 个可独立运行的 Java 文件**，按 10 个部分分文件夹存放。
已用 JDK 17 逐一完成编译与运行验证（代码本身兼容 Java 8）。

## 运行方式

每个文件都可单独编译运行（在该文件所在目录打开终端）：

```
javac -encoding UTF-8 文件名.java
java 文件名（不含 .java）
```

例如：

```
cd P02_数据类型与类型转换
javac -encoding UTF-8 OverflowDemo.java
java OverflowDemo
```

> 说明：
> 1. 视频中无法编译的演示片段（如 `byte myNum = 128;`、抽象类实例化、继承 final 类等）均以注释形式保留在对应文件中。
> 2. 视频第 7 集 `setAge` 中 `int 字段 + String.valueOf` 的重构中间态本身不能编译，这里按讲解意图整理为可运行版本，详见笔记原文说明。
> 3. 第 9.3 集视频画面里的 `remove("Two")` 与 Integer 集合类型不匹配（无效果），代码中改为 `remove(Integer.valueOf(5))` 并加注释。
