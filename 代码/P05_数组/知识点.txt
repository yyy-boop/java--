第5集 数组

一、数组基础

1. 数组声明写法：类型[] 变量名 = {元素1, 元素2, ...}，这是静态初始化。

2. 动态初始化用 new 类型[长度]，先指定长度，元素取默认值（数字为 0）。

3. 数组在内存中是一块连续空间，一旦创建长度不可改变。

4. 数组中只能存储同一种类型的元素。

5. 数组下标从 0 开始，可访问范围是 0 到 长度-1，超出范围会报数组下标越界异常。

6. 访问和修改元素都通过下标，例如 numbers[0]、numbers[2] = 25。

7. 获取数组长度用 length，它是属性而不是方法，写法为 numbers.length。

二、数组遍历与多维数组

1. 普通 for 循环按下标遍历，写法为 for (int i = 0; i < arr.length; i++)，可以拿到下标。

2. 增强 for 循环直接逐个取元素，写法简洁，但拿不到下标。

3. 多维数组就是数组里放数组：二维数组用两个中括号 int[][]，三维用三个。

4. 二维数组静态初始化：
   int[][] matrix = {{1,2,3},{4,5,6},{7,8,9}};

5. 遍历二维数组需要双层 for 循环，外层遍历行，内层遍历列。

三、Arrays 工具类常用方法（使用前 import java.util.Arrays;）

1. Arrays.sort(数组)：对数组升序排序，底层使用快速排序。

2. 直接用 = 把数组赋给另一个变量是浅拷贝，两个变量指向同一地址，改一个另一个也跟着变。

3. Arrays.copyOf(原数组, 新长度)：重新开辟内存复制数组（深拷贝）。
   新长度等于原长度则完全一致；
   小于原长度只取前几个元素；
   大于原长度，数字类型补 0，引用类型补 null。

4. Arrays.fill(数组, 值)：把数组所有元素填充成指定值。

5. Arrays.equals(数组1, 数组2)：比较两个数组的内容是否相同；用 == 比较的是地址。

6. Arrays.toString(数组)：把一维数组转成便于阅读的字符串。

7. 多维数组要用 Arrays.deepToString()，直接用 toString 只会打印出内层地址。
