第1集 Hello World —— 程序入口与运行

1. Java 程序存放在以 .java 结尾的文件中，每个文件由类构成，类名必须与文件名相同。

2. 类中有一个 main 方法，它是程序的入口，固定写法为：
   public static void main(String[] args)

3. IDEA 可以自动完成编译并运行；手动在终端操作时，先用 javac 把 .java 编译成 .class 字节码文件，再用 java 命令运行。

4. 运行 Java 代码需要先安装 JDK 并配置环境变量。JDK 包含编译工具 javac、运行环境 JRE 和其他工具。

5. JRE 中的 JVM 把字节码转换成不同设备上的机器码执行，同一份字节码可以在不同系统上运行，这就是 Java 跨平台（一次编译，到处运行）的原因。

对应代码见同文件夹的 Main.java。
