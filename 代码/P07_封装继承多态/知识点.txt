第7集 封装、继承、多态

一、封装

1. 封装的含义：把对象的属性和方法包装在一起，对外隐藏内部实现细节，只暴露必要的访问入口。

2. 典型做法：字段用 private 私有化，再提供 public 的 getter 和 setter 供外部读取和修改。

3. getter 命名为 getXxx，返回对应字段；setter 命名为 setXxx，接收参数给字段赋值。

4. 封装的好处是可以在 setter 中加入校验逻辑，例如年龄必须在 0 到 300 之间，不合法就拒绝赋值。

5. 封装还可以隐藏数据的真实存储形式：例如数据库里性别存 0 和 1，对外通过方法展示成"女"和"男"，内部实现改变时外部使用方式不受影响。

二、继承

1. 继承让一个类（子类）可以复用另一个类（父类）的属性和方法，用关键字 extends 表示。

2. 子类构造方法会先调用父类的构造方法，调用父类构造用 super(参数)，它必须写在子类构造方法的第一行。

3. 子类方法中用 super.成员 访问父类的字段或方法，用 this.成员 访问自己的成员。

4. 方法重写（override）：子类定义与父类同名同参数的方法，调用时以子类的实现为准；可以在重写方法中用 super.方法() 先调用父类版本。

5. 成员变量不重写：父类引用指向子类对象时，访问字段取父类的，调用方法取子类的。

6. final 修饰的方法不能被重写，final 修饰的类不能被继承。

三、多态

1. 多态指同一个方法在不同对象上表现出不同行为，前提是继承和方法重写。

2. 多态的形式：父类引用指向子类对象，例如 Animal a = new Dog(); 调用 a.sound() 执行的是 Dog 的实现。

3. 向上转型：把子类对象赋给父类引用，自动完成，但只能调用父类中声明过的方法。

4. 向下转型：把父类引用强转回子类类型，例如 (Dog)a，转型后才能调用子类特有方法（如 fetch）。

5. 向下转型前应先用 instanceof 判断对象的真实类型，判断为真再转型，避免类型转换异常。

6. 多态的好处：可以用统一的父类类型管理一组不同子类对象，遍历调用同一个方法时各自执行自己的版本，新增子类时原有代码基本不用改。

四、父类构造调用顺序（多态的一个坑）

1. 创建子类对象时，先执行父类构造方法，再执行子类构造方法。

2. 如果父类构造方法中调用了被子类重写的方法，此时子类构造还没执行，子类字段仍是默认值 0（引用类型为 null）。

3. 因此父类构造中打印出的子类字段是 0，子类构造执行后字段才被赋成传入的值。

4. 结论：尽量不要在父类构造方法中调用可能被子类重写的方法。
