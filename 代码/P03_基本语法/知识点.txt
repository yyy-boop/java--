第3集 基本语法：运算符、循环、分支

一、运算符

1. 算术运算符：加 +、减 -、乘 *、除 /、取模 %。

2. int 与 int 相除结果仍是 int，小数部分被舍弃，10 / 3 得 3；% 取余数，10 % 3 得 1。

3. 若把除数声明为 float（如 3f），则可以得到小数商 3.3333333。

4. 关系运算符：>、<、==、!=，运算结果是布尔值 true 或 false。

5. 逻辑运算符：&& 与、|| 或、! 非。

6. 赋值运算符：+=、-= 等，c += 3 等价于 c = c + 3。

7. 三元运算符：条件 ? 值1 : 值2；条件为真返回值1，为假返回值2。

二、循环语句

1. for 循环：先初始化，再判断条件，条件成立执行循环体，最后执行迭代语句，适合循环次数明确的场景。

2. 增强 for 循环（for-each）：依次取出数组或可迭代对象中的每个元素，写法简洁，但拿不到下标。

3. while 循环：先判断条件，条件成立才执行循环体，适合次数不明确的场景。

4. do-while 循环：先执行一次循环体，再判断条件，因此即使条件一开始就不成立，循环体也至少执行一次。

5. 循环内部可以用 break 跳出整个循环，用 continue 跳过本次循环进入下一次判断。

三、分支语句

1. if 分支：判断条件是否为真，为真就执行对应代码块。

2. 多分支用 if ... else if ... else：从上到下判断，一旦某个条件为真就执行该分支，后面的不再判断。

3. switch 分支：接受一个值，依次匹配各个 case，匹配成功就执行对应语句。

4. 每个 case 末尾通常要写 break 跳出 switch，否则会继续向下执行后面的 case（case 穿透）。

5. 所有 case 都不匹配时执行 default 分支。
