第8集 抽象类、接口、内部类

一、抽象类

1. 用 abstract 修饰的类是抽象类，用 abstract 修饰的方法是抽象方法。

2. 抽象方法只有方法声明，没有方法体，以分号结尾，例如 public abstract void sound();

3. 含有抽象方法的类必须声明为抽象类；抽象类中也可以有普通方法和字段。

4. 抽象类不能直接 new 对象，因为其中的抽象方法没有实现。

5. 普通类继承抽象类后，必须实现（重写）父类所有的抽象方法，否则自己也得声明为抽象类。

6. 抽象类的作用：为多个子类规定统一的方法模板，把具体实现交给子类完成。

二、接口

1. 接口用 interface 声明，是一种完全抽象的类型，类实现接口用关键字 implements。

2. 接口中的变量默认是 public static final 的常量；方法默认是 public abstract 的抽象方法。

3. 实现接口的类必须重写接口中的所有抽象方法，否则该类要声明为抽象类。

4. 接口中可以定义 default 默认方法，它带有方法体，实现类可以直接使用或重写，作用是在不破坏已有实现类的前提下给接口扩展功能。

5. 接口中可以定义 static 静态方法，通过接口名直接调用。

6. 一个类只能继承一个父类，但可以同时实现多个接口，用逗号隔开，接口弥补了 Java 单继承的限制。

三、内部类

1. 成员内部类：定义在类内部、方法外部，属于外部类的对象，需要先创建外部类对象再创建内部类对象，可以直接访问外部类的成员。

2. 静态嵌套类：用 static 修饰的内部类，属于外部类本身，不依赖外部类对象，只能直接访问外部类的静态成员。

3. 局部内部类：定义在方法内部，只在该方法内有效，作用域局限于方法。

4. 匿名内部类：没有类名的内部类，通常在 new 一个接口或抽象类时直接写出方法实现，用完即弃，适合只使用一次的场景。
